# OCG 2003

2003年12月31日時点の日本OCGを忠実に再現する、スマートフォン向けシングルプレイゲームです。

## 現在の実装

- Vol.1（公式収録40種類・1パック5枚）
- 1日10パック制（日本時間0:00更新）
- 好きなパックを選べるパック選択画面
- 端末内に保存されるカードコレクション
- 所持カードから作成・保存できるメインデッキ
- カード検索、種類絞り込み、同名3枚制限
- モンスター戦闘対応のCPUデュエル
- Vol.1収録の魔法・罠カード10種の効果
- 状況に応じて魔法・罠を使うCPU
- 生け贄にするモンスターの手動選択
- 召喚した次の自分ターン以降の表示形式変更
- ドローからエンドまでのフェイズ表示と操作制限
- 自分・CPUの墓地と使用済みカードの追跡
- 手札・フィールド・墓地のカード詳細表示
- 攻撃・守備表示ごとの戦闘破壊判定
- 勝利時にCPUデッキからランダムで1枚獲得
- スマートフォン対応画面

カード効果とCPU思考は、収録カードの追加に合わせて拡張します。

## プレイ

GitHub Pages: https://drteddy0304.github.io/OCG2003/

## 開発

Node.js 22.13以降が必要です。

```bash
npm install
npm run dev
npm test
```

## 開発原則

- 各コミットは単独で動作する状態にする
- 機能を小さく分割する
- 既知の不具合を残したまま次へ進まない
- 2003年12月31日時点のカード、ルール、裁定を基準にする
