# OCG 2003

2003年12月31日時点の日本OCGを忠実に再現する、スマートフォン向けシングルプレイゲームです。

## 現在の実装

- 開発用テストパック（1パック5枚）
- 6種類のテスト用カードデータ
- 端末内に保存されるカードコレクション
- スマートフォン対応画面

デッキ編集とCPU戦は、Phase 1の後続ビルドで追加します。

## プレイ

GitHub Pages: https://drteddy0304.github.io/OCG2003/

## 開発

Node.js 22.13以降が必要です。

```bash
npm install
npm run dev
npm test
```

## 開発原則

- 各コミットは単独で動作する状態にする
- 機能を小さく分割する
- 既知の不具合を残したまま次へ進まない
- 2003年12月31日時点のカード、ルール、裁定を基準にする
